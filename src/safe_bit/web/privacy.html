What this service does

Safe Bit creates and verifies committed bits. You send a secret and a timestamp, and the service returns a commitment and a bit. Later, you can send them back to check that they match.

Data we process

  • Secrets, timestamps, commitments and bits that you send in requests. They are used only to answer that request.
  • Your IP address and request metadata, which your connection necessarily reveals to the server so it can respond to you.

Do not put personal data in your secrets. We cannot tell what a secret contains.

Data we store

The only data stored in the service's database is its encryption keys, with the time range each key is valid for. The keys are generated randomly and contain no personal data.

We do not store the secrets, commitments or bits that you send. We do not have user accounts.

Logs

The application does not write access logs. It logs only errors, and error logs do not record request contents.
